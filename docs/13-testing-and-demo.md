# 13 — Testing and demo

## Tests

### Contract (Rust)
- Merkle: verify shared vectors; reject a wrong proof, a wrong amount, a wrong salt.
- EVM signature: verify vectors generated by `viem` (`packages/core/test-vectors/claim-message.json`); reject a wrong address, a modified target, an expired message.
- Lifecycle: create → approve (threshold) → fund (exact, partial, overfund returns excess) → Active.
- Claims: success; double claim rejected; claim after deadline rejected; claim from a non-recipient rejected; cross-run accounting.
- Failed `ft_transfer` → callback reverts the claim (sandbox test with an unregistered account and storage failure).
- `reopen_claim` only by approvers; `reclaim_unclaimed` only after the deadline, exact remainder.
- Pause blocks everything except views.

### Core (TypeScript, vitest)
- CSV: delimiters, BOM, blank rows, quoted commas, `$1,200.50`, `1.200,50`.
- Normalization: amount to base units; chain inference; address validation.
- Every rule R001–R011 with a positive and a negative case.
- Merkle: TS output equals the vectors; proofs verify.
- Report: canonical JSON stable across key order; hash matches.
- Claim message: exact bytes; matches the contract's reconstruction.
- AI: schema validation rejects bad JSON; signature verification with a recorded real fixture (save one real response + signature to `test-vectors/ai/`).

### Integration
- `near-workspaces` sandbox: deploy mock USDC + Blindroll; full run with 3 recipients (2 EVM, 1 NEAR).
- `scripts/e2e-testnet.ts`: same flow on testnet with real accounts; prints tx links.

## Demo script (2 minutes)

1. **Problem (15 s):** "DAOs pay contributors from messy spreadsheets, on public chains, to addresses nobody verified."
2. **Upload (20 s):** messy CSV → private AI maps columns → table shows a duplicate (error) and an outlier (warning).
3. **Fix + report (15 s):** remove the duplicate, override the outlier with a reason → finalize → report hash and Merkle root.
4. **Approve + fund (15 s):** two approvers sign, fund USDC → run Active (NearBlocks links).
5. **Claim (30 s):** contributor connects MetaMask, signs, sees only their row, compares payout options, claims gas-free → delivered.
6. **Failure path (10 s):** a refunded payout → approver reopens → claim again.
7. **Proof (15 s):** verify page: report hash matches the contract, AI signature ✓. Export CSV.
